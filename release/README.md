# VNote 0.1.1

VNote는 수업·회의를 녹음하고 한국어·영어 대본을 만드는 맥 앱입니다.  
받아쓰기와 화자 분리는 맥 안에서 처리합니다.  
프로젝트별 노트, PDF 자료, 대본과 선택적인 ChatGPT 채팅을 한 화면에서 사용합니다.

## 요구 사항

- Apple Silicon 맥(M1 이상). Intel 맥·Windows는 이 배포판에서 지원하지 않습니다.
- **macOS 14.0 (Sonoma) 이상**.
- 메모리 16GB 이상 권장. 8GB에서는 경량 모델 세트를 선택하고 다른 앱을 줄이세요.
- 앱·모델용 여유 공간 약 6GB 이상, 설치·다운로드 중에는 10GB 이상 권장. 모델 세트·캐시 버전에 따라 달라집니다. 녹음과 PDF 저장 공간은 별도입니다.
- 처음 모델을 받을 때 인터넷이 필요합니다. 받은 뒤 받아쓰기는 오프라인으로 사용합니다. ChatGPT와 업데이트 확인은 인터넷이 필요합니다.

## 설치와 처음 실행

1. 릴리스의 `VNote_0.1.1_aarch64.dmg`를 내려받아 엽니다.
2. VNote를 **Applications(응용 프로그램)** 폴더로 끌어 넣습니다.
3. 응용 프로그램 폴더의 VNote를 엽니다.
4. 개발자 확인 때문에 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 선택하고 다시 엽니다. 이 배포판은 ad-hoc 서명이며 Apple 공증을 받지 않았습니다.
5. 첫 실행 안내에서 마이크를 허용하고 정밀(full) 또는 경량(lite) 모델을 받습니다. 다운로드가 완료되어야 다음 단계로 넘어갑니다.
6. ChatGPT 연결은 건너뛰어도 됩니다. 프로젝트와 노트를 만든 뒤 녹음하거나 기존 오디오·PDF를 가져오세요.

스크린샷 예정: `images/install-dmg.png`, `images/open-anyway.png`, `images/first-run-models.png`, `images/chatgpt-connect.png`. 아직 이미지 파일은 포함하지 않았습니다.

업데이트는 설정에 표시된 버전과 최신 공개 릴리스를 비교하고 다운로드 페이지를 엽니다. 새 앱으로 교체한 뒤 마이크 권한을 다시 물을 수 있습니다. **시스템 설정 → 개인정보 보호 및 보안 → 마이크**에서 VNote를 허용하세요.

## ChatGPT 연결

첫 실행 안내 또는 설정에서 **ChatGPT 로그인**을 누르고 열린 브라우저에서 로그인합니다. 연결 상태가 표시되면 노트 질문·요약·자료 용어 추출을 사용할 수 있습니다. 이 버전은 번들 Codex CLI 로그인을 이용합니다.

ChatGPT로 로그인한 사용은 계정의 구독/Codex 사용 한도에서 차감됩니다. 사용 가능 모델과 한도는 계정·플랜에 따라 다릅니다. API 키를 입력하는 방식은 이 앱에서 제공하지 않습니다. 공식 안내: [로그인](https://learn.chatgpt.com/docs/auth), [사용 한도](https://learn.chatgpt.com/docs/pricing).

설정의 **연결 해제**로 앱의 Codex 로그인을 해제합니다. 이미 저장한 노트·채팅 기록은 로컬에 남습니다. 로그인되지 않아도 녹음·로컬 받아쓰기는 사용할 수 있습니다.

## 개인정보와 녹음 동의

녹음, 대본, 내 노트, 가져온 PDF, 채팅 기록과 모델 캐시는 `~/Library/Application Support/VNote`에 저장합니다. 기존 개인용 `VoiceNote` 데이터와 별도입니다. 받아쓰기·화자 분리에서는 음성과 대본을 OpenAI로 보내지 않습니다.

ChatGPT에 질문하거나 PDF 용어 추출을 실행하면 질문과 해당 노트의 대본, 내 노트, 자료에서 추출한 텍스트, 최근 대화 일부가 OpenAI로 전송됩니다. 원본 오디오와 PDF 파일 자체를 업로드하는 기능은 없습니다. **ChatGPT가 연결된 상태에서 PDF를 가져오면 용어 추출이 자동 실행되어 PDF의 추출 텍스트가 전송됩니다.** 자료 화면의 용어 추출 버튼도 전송을 실행합니다. 연결 동작 자체는 노트 내용을 전송하지 않습니다. 계정의 데이터 처리 정책은 OpenAI 및 소속 워크스페이스 설정에 따릅니다.

모델 다운로드는 Hugging Face와 FluidAudio 모델 호스트에, 업데이트 확인은 GitHub에 연결합니다. 앱 로그는 오류 종류와 처리 단계만 기록하며 대본·프롬프트 원문을 기록하지 않습니다. Codex 로그인 자격 증명은 별도 앱 Codex 홈 또는 OS 자격 증명 저장소에 보관될 수 있습니다.

녹음 전 참여자에게 알리고 필요한 동의를 받으세요. 학교·회사·기관의 녹음 규칙을 확인하세요.

## 문제 해결

- **다운로드가 0%에서 안 움직일 때**: 연결 중 표시가 끝나지 않으면 인터넷 연결을 확인하세요. 다운로드가 60초 동안 늘지 않으면 네트워크를 확인한 뒤 **다시 시도**를 누르세요. 이어받기는 기존 캐시를 사용합니다.
- **앱을 응용 프로그램 폴더에서 실행하세요**: 디스크 이미지나 다운로드 폴더에서 바로 실행하지 말고 VNote를 **응용 프로그램(Applications)** 폴더로 옮긴 뒤 다시 여세요.
- **엔진 오류**: 앱을 완전히 종료하고 다시 실행하세요. 설정에서 모델 상태를 확인하고 실패한 녹음의 재시도를 누르세요. macOS 14.0 (Sonoma) 이상인지 확인하세요. 계속 실패하면 설정의 **로그 폴더 열기**에서 로그를 확인합니다.
- **모델 다시 받기**: 설정에서 세트를 고르고 다운로드를 누르세요. 중단된 다운로드는 캐시를 사용해 다시 시도합니다. 손상된 캐시가 의심되면 앱을 종료한 뒤 **설정 → 데이터 폴더 열기**로 찾은 `models` 폴더만 별도 위치로 옮겨 백업하고 다시 받으세요. `audio`, `notes`, `transcripts`는 옮기지 마세요.
- **마이크가 안 됨**: 시스템 설정의 마이크 권한과 입력 장치를 확인한 뒤 앱을 다시 실행하세요.
- **ChatGPT 오류**: 설정에서 연결 해제 후 재로그인하세요. 인터넷과 계정 사용 한도를 확인하세요. 로컬 받아쓰기는 계속 사용할 수 있습니다.
- **로그 위치**: `~/Library/Application Support/VNote/logs/app.log`. 설정에서 로그 폴더를 열 수 있습니다.
- **자료 글자가 안 추출됨**: 이미지로 스캔한 PDF는 OCR을 지원하지 않습니다. 텍스트 PDF를 사용하세요.
